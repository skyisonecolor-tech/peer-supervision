# 동료장학 수업공개 계획 취합 · 수업 참관 신청

학교 동료장학 수업공개 계획(동료장학 / 전교사 대상 공개수업)을 선생님들께 받아 정리하고, 취합이 끝나면 수업 참관 신청까지 받는 웹 페이지입니다.
화면은 `index.html` 한 파일이고, 데이터는 구글 시트(Apps Script)에 저장됩니다.

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 교사 화면 + 관리자 화면 (GitHub Pages로 공개) |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣는 서버 코드 (**비밀번호 없음**) |
| `README.md` | 이 설명서 |

## 처음 설치

### 1. 구글 시트 + 서버 코드
1. 구글 시트를 새로 만듭니다.
2. 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용을 전체 붙여 넣고 저장합니다.
3. 왼쪽 ⚙ **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `ADMIN_PW`
   - 값: 관리자 비밀번호
4. 함수 `loadAll` 을 한 번 실행해 권한을 허용합니다.
5. 배포 → 새 배포 → 유형 **웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포
6. 나온 `https://script.google.com/macros/s/…/exec` 주소를 `index.html` 의 `SCRIPT_URL` 에 넣습니다.

### 2. GitHub Pages
1. 이 저장소의 Settings → Pages → Branch: `main` / `(root)` → Save
2. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.
3. 이 주소를 선생님들께 안내합니다.

> 파일을 고쳐 올리면 반영까지 몇 분 걸릴 수 있습니다. 바로 안 바뀌면 새로고침(Ctrl+F5) 하세요.

## 서버 코드를 고쳤을 때
Apps Script에 새 코드를 붙여 넣고 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**.
이렇게 하면 웹 앱 주소가 바뀌지 않습니다.

## 운영 순서 (관리자 모드)
1. **진행 단계** 탭: 학년도·학기 선택, 필수 참관 횟수 저장
2. **명단 · 제출 현황** 탭: 참여 명단 엑셀 업로드 (교과 · 교사 · 전교사 공개수업 대상 유무 → 대상이면 `1`)
3. **날짜 설정** 탭: 전교사 공개 날짜, 수업공개 제외 날짜, 참고 날짜
4. **시간표** 탭: 주간 시간표 업로드, 시간표 변경일, 참관 신청과 시간표 겹침 확인
5. 진행 단계 → **입력 개시** → (취합) → **입력 마감**
6. **참관 신청 시작** → (신청) → **참관 신청 마감**
7. 엑셀 다운로드 / 출력
8. 다음 학기: 진행 단계 탭 아래 **초기화** (지우기 전에 구글 시트 안에 백업 탭이 자동 생성됨)

관리자가 올리거나 바꾼 내용은 선생님 화면에 자동 반영됩니다(평소 30초, 참관 신청 화면 10초 간격).

## 보안 메모
- 관리자 비밀번호는 `index.html` 에도 `Code.gs` 에도 들어 있지 않습니다. 구글 Apps Script의 스크립트 속성에만 저장됩니다.
- 비밀번호를 10번 틀리면 10분 동안 관리자 기능이 잠깁니다.
- `index.html` 에 들어 있는 웹 앱 주소(`SCRIPT_URL`)를 아는 사람은 제출된 계획(교사 이름, 수업 일정)을 읽을 수 있습니다. 수정·삭제는 비밀번호가 있어야 합니다.
- 검색엔진에 노출되지 않도록 `noindex` 를 설정해 두었습니다.

## 테스트 모드
`SCRIPT_URL` 을 빈 문자열(`''`)로 두면 서버 없이 이 브라우저에만 저장되는 테스트 모드로 동작합니다. 테스트 모드의 관리자 비밀번호는 `test` 입니다.
